# Templates and recipes

Recipes turn the rules into repeatable outputs. Each one says what to read, the structure to follow, and where the interference goes.

| Output | Recipe | Working file |
|---|---|---|
| Deck (capabilities, pitch, workshop, report) | [`deck/README.md`](deck/README.md) | [`deck/deck.html`](deck/deck.html) |
| Proposal / SOW | [`proposal.md`](proposal.md) | Use the deck grid, or the sheet theme in a doc |
| Case study | [`case-study.md`](case-study.md) | meddle.studio `_work/*.md` front matter |
| LinkedIn / social post | [`linkedin-post.md`](linkedin-post.md) | Tiles use the deck grid at 1080×1080 / 1080×1350 |
| Email (intro, follow-up, proposal send) | [`email.md`](email.md) | — |
| Landing page / web section | [`landing-page.md`](landing-page.md) | `components/components.css` |
